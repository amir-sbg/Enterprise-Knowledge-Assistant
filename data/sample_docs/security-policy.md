# Security Data Handling Policy

Restricted data includes customer records, source code with secrets, payroll files, audit reports, incident reports, and regulated health or financial data. Employees must classify documents before sharing them externally.

Restricted data may be sent outside the company only after the recipient is approved, the business purpose is documented, and encryption is enabled. The sender must use an approved transfer channel and record the transfer in the security ticket.

If a restricted file is sent to the wrong recipient, the employee must open a security incident within one hour, notify the security team, and avoid asking the recipient to forward or delete evidence before security review.

Public data can be shared without a ticket, but employees should still avoid copying internal comments, private links, or hidden spreadsheet tabs into external channels.
